Highlights

1

Labs can already leave agents running for days. A long run still fails without a written brief.

OpenAI, Anthropic and Google have all described multi-day agent work. Nate B. Jones's useful question is why most of us still wake up to a mess: the assignment, and the decisions that changed mid-way, were never left in a form the next agent could use.

2

Treat the work like code — decisions, methods and examples — where any agent can read them.

A one-time snapshot of your opinion is not enough. A record that any model can walk is also a hedge against an assistant locking in your memory and history.

3

A one-person media operation can already run this way, if taste and the script stay human.

Louise de Sadeleer keeps weekly routines, writes scripts by hand, and turns methods into skills. A bot is for a role or a project; a skill is for a method. The test: could a second person, or a second agent, continue tomorrow without a briefing from you?

4

Most of the work no longer needs the most expensive model, and the human still sits at the grill and the retro.

Jones, with checks against Ramp and Infosys, argues that use is going up while the bill is not. Value moves up the stack, and the buyer will want some of the saving. Matt Pocock's hour-long build shows where a person still has to sit: the brief, the risky changes, and the review at the end.

1. The overnight run, and treating the work like code

Speaker Nate B. Jones
Disclosure Offers a paid context kit on Substack.
Lane entry FR-014
Source Condensed from the 21 November 2026 briefing (20:36)

Narrator: In recent weeks OpenAI, Anthropic and Google have each described agents working for days. Anthropic said more than a thousand agents worked for eight days on a prototype operating system that, it says, boots on a laptop. Jones's point is that a long run still fails when the brief is ambiguous and mid-way decisions never get written down for the next agent. Treat project information like code: decisions, examples and changed instructions, in a place any person or model can read.

Those systems can work for a long time if you set them up right. Most of us have not. The story is not "a thousand agents for eight days." The story is that a long run fails for want of a structured brief, and because what you learn mid-way never gets written down for the next agent. You pay twice. The right context is not just a pile of facts. It is the decisions you made, the examples you found, and the instructions you changed when you changed your mind.Nate B. Jones, condensed from the 21 November briefing; checked against OpenAI (2 Nov), Anthropic (9 Nov) and Gemini 4 Carbon (28 Oct)
